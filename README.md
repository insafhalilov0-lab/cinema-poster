# cinema-poster

Киноафиша с карточками фильмов.

## Что использовал
- HTML: семантические теги, `div`, списки, картинки, ссылки (якорь)
- CSS: тёмная тема, типографика, тени, рамки, скругления
- CSS: Flexbox (`display: flex`, `justify-content`, `align-items`, `gap`) для расположения текста и картинки в ряд
- CSS: `:hover` эффекты

## Чему научился
- Выстраивать элементы в ряд с помощью Flexbox
- Делать карточки с фиксированной шириной и выравнивать их по центру экрана
- Ограничивать размеры картинок, чтобы они не ломали вёрстку
- Работать с якорями для кнопки «Наверх»
